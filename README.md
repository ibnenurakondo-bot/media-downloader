# মিডিয়া ডাউনলোডার (Flask + yt-dlp + gallery-dl + ffmpeg)

লিংক দিয়ে ভিডিও (Full HD পর্যন্ত), অডিও (MP3) ও ছবি ডাউনলোড করার ওয়েব অ্যাপ।
**শুধু নিজের কনটেন্ট, পাবলিক ডোমেইন/CC বা অনুমতিপ্রাপ্ত কনটেন্টের জন্য ব্যবহার করুন।**
বেশিরভাগ সাইটের শর্তাবলি ডাউনলোড নিষিদ্ধ করে, আর কপিরাইট লঙ্ঘনের দায় ব্যবহারকারীর।

> Hugging Face-এ ডেপ্লয় করলে উপরের `---` ব্লকটি রাখতে হবে। GitHub/Render-এ রাখলেও সমস্যা নেই।

## ফোল্ডারের ফাইল
| ফাইল | কাজ |
|---|---|
| `app.py` | ব্যাকএন্ড (জব, প্রগ্রেস, কুকি, অটো-আপডেট) |
| `templates/index.html` | ফ্রন্টএন্ড (বাংলা UI) |
| `Dockerfile`, `start.sh` | কনটেইনার ও স্টার্টআপ (ffmpeg সহ) |
| `render.yaml` | Render-এর জন্য ব্লুপ্রিন্ট |

## ক) লোকালি চালানো
    pip install -r requirements.txt     # সাথে ffmpeg ইনস্টল থাকতে হবে
    python app.py                       # http://localhost:7860

## খ) Hugging Face Spaces-এ ডেপ্লয় (ফ্রি, সুপারিশকৃত)
1. huggingface.co-তে অ্যাকাউন্ট খুলুন → **New Space**।
2. Space name দিন, **SDK: Docker → Blank** বেছে নিন, Hardware: **CPU basic (free)**।
3. **Files** ট্যাবে গিয়ে এই ফোল্ডারের সব ফাইল আপলোড করুন (`templates/` ফোল্ডারসহ)।
   অথবা Git দিয়ে: `git clone <space-url>` → ফাইল কপি → `git add . && git commit && git push`।
4. **Settings → Variables and secrets** থেকে নিচের সিক্রেটগুলো যোগ করুন (ঐচ্ছিক, নিচে দেখুন)।
5. **Logs** ট্যাবে বিল্ড দেখুন। "Running" হলে অ্যাপ লাইভ।
6. ডাউনলোড ঠিকমতো না চললে Space-এর সরাসরি লিংকে (`https://<user>-<space>.hf.space`) খুলুন, iframe এড়াতে।

## গ) Render-এ ডেপ্লয় (ফ্রি টিয়ার)
1. প্রজেক্টটি GitHub রিপোতে পুশ করুন।
2. Render → **New → Blueprint** → রিপো বেছে নিন (`render.yaml` নিজে থেকে পড়বে)।
3. সিক্রেটগুলো Render ড্যাশবোর্ড থেকে দিন। ফ্রি টিয়ার নিষ্ক্রিয় থাকলে ঘুমিয়ে যায়, প্রথম লোডে ~১ মিনিট লাগে।

## ঘ) এনভায়রনমেন্ট ভেরিয়েবল / সিক্রেট
| নাম | কাজ | ডিফল্ট |
|---|---|---|
| `ACCESS_CODE` | সেট করলে অ্যাপ ব্যবহারে এই কোড লাগবে | বন্ধ |
| `COOKIES_B64` | কুকি ফাইলের base64 (নিচে দেখুন) | নেই |
| `ADMIN_TOKEN` | জরুরি আপডেটের জন্য অ্যাডমিন টোকেন | বন্ধ |
| `MAX_MINUTES` | ভিডিওর সর্বোচ্চ দৈর্ঘ্য (মিনিট) | 30 |
| `MAX_IMAGES` | এক লিংকে সর্বোচ্চ ছবি | 30 |
| `RATE_LIMIT` | প্রতি IP-তে ঘণ্টায় অনুরোধ | 10 |
| `UPDATE_HOURS` | কত ঘণ্টা পর পর yt-dlp আপডেট (0 = বন্ধ) | 24 |
| `UPDATE_ON_BOOT` | স্টার্টে আপডেট (1/0) | 1 |

## ঙ) কুকি সাপোর্ট (লগইন-নির্ভর বা ব্লক হওয়া লিংকের জন্য)
YouTube, Instagram ইত্যাদি ডেটা-সেন্টার IP-তে প্রায়ই "Sign in" চায়। তখন কুকি দিলে কাজ হতে পারে।

1. ব্রাউজারে সংশ্লিষ্ট সাইটে লগইন করুন। **একটি আলাদা/অপ্রয়োজনীয় অ্যাকাউন্ট ব্যবহার করুন**, মূল অ্যাকাউন্ট নয়।
2. Chrome/Firefox-এর "Get cookies.txt LOCALLY" এক্সটেনশন দিয়ে `cookies.txt` (Netscape ফরম্যাট) এক্সপোর্ট করুন।
3. base64 বানান:
   - Linux/Mac: `base64 -w0 cookies.txt` (Mac-এ `base64 -i cookies.txt`)
   - Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cookies.txt"))`
4. ফলাফলটি `COOKIES_B64` সিক্রেট হিসেবে বসান। রিস্টার্ট হলেই কাজ করবে।

**সতর্কতা:** কুকি দিলে সবার ডাউনলোড আপনার অ্যাকাউন্টের নামে হবে, এতে অ্যাকাউন্ট ব্লক হতে পারে। তাই কুকি দিলে অবশ্যই `ACCESS_CODE` সেট করুন বা Space **Private** রাখুন। কুকি কখনও রিপোতে কমিট করবেন না (`.dockerignore`-এ `cookies.txt` বাদ দেওয়া আছে, `.gitignore`-এও রাখুন)।

## চ) আপডেট (yt-dlp প্রায়ই ভাঙে, তাই জরুরি)
- স্টার্টে ও প্রতি ২৪ ঘণ্টায় নিজে নিজে আপডেট হয়। নতুন ভার্সন পেলে চলমান জব শেষ হওয়ার পর সার্ভার নিজে রিলোড হয়।
- এখনই আপডেট করতে (`ADMIN_TOKEN` সেট থাকলে):
      curl -X POST https://<আপনার-অ্যাপ>/api/admin/update -H "X-Admin-Token: <টোকেন>"
- বর্তমান ভার্সন দেখতে: `https://<আপনার-অ্যাপ>/health`

## ছ) সমস্যা হলে
| লক্ষণ | সম্ভাব্য কারণ ও সমাধান |
|---|---|
| "Sign in to confirm you're not a bot" | কুকি যোগ করুন (ঙ) |
| তথ্য আনা যায় না / ৪০৩ | `/health` থেকে ভার্সন দেখে আপডেট করুন (চ) |
| ভিডিও মার্জ হয় না | লোকালি চালালে ffmpeg ইনস্টল আছে কি দেখুন |
| "সার্ভার ব্যস্ত" | একসাথে ৩টির বেশি জব চলছে, একটু পরে চেষ্টা করুন |
| ফ্রি হোস্টে ধীর/ফেল | ফ্রি টিয়ারে CPU/RAM কম, ছোট ভিডিও বা কম রেজোলিউশন দিন |
| ছবি পাওয়া যায় না | gallery-dl সব সাইট সাপোর্ট করে না; অনেক সাইটে কুকি লাগে |

## নিরাপত্তা সংক্ষেপে
- প্রাইভেট/লোকাল নেটওয়ার্ক ও `file://` লিংক ব্লক করা (SSRF সুরক্ষা)।
- রেট লিমিট, ভিডিও দৈর্ঘ্যের সীমা, একসাথে সর্বোচ্চ ৩ জব।
- কুকি শুধু সার্ভারের সিক্রেট থেকে আসে (ইউজার আপলোড নয়), জব শেষে কপি মুছে যায়।
- অস্থায়ী ফাইল ১৫ মিনিট পর স্বয়ংক্রিয়ভাবে মুছে যায়।
