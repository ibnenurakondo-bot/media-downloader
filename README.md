# মিডিয়া ডাউনলোডার (নিজের কম্পিউটার বা ফোনে চলবে)

ভিডিও (Full HD পর্যন্ত), অডিও (MP3) ও ছবি ডাউনলোডের অ্যাপ। চলে আপনার নিজের ডিভাইসে, তাই ক্লাউড সার্ভারের মতো IP ব্লকের সমস্যা সাধারণত হয় না।

> **নিজের কনটেন্ট, পাবলিক ডোমেইন/CC বা অনুমতিপ্রাপ্ত কনটেন্টের জন্য ব্যবহার করুন।** বেশিরভাগ সাইটের শর্তাবলি ডাউনলোড নিষিদ্ধ করে, আর কপিরাইটের দায় ব্যবহারকারীর।

## ক) কম্পিউটারে (Windows / Mac / Linux)
1. **Python 3.10+** ইনস্টল করুন: https://www.python.org/downloads/ (Windows-এ ইনস্টলারে **"Add python.exe to PATH"** টিক দিন)।
2. জিপ ফাইল আনজিপ করুন।
3. **Windows:** `run-windows.bat` ফাইলে ডাবল-ক্লিক করুন।
   **Mac/Linux:** টার্মিনালে ফোল্ডারে গিয়ে `bash run-mac-linux.sh`।
4. প্রথমবার ১–২ মিনিট প্যাকেজ নামাবে (ffmpeg আলাদা ইনস্টল লাগবে না, সাথেই আসে)। এরপর ব্রাউজারে অ্যাপ নিজে খুলবে (`http://127.0.0.1:7860`)।
5. প্রতিবার চালানোর সময় `yt-dlp` নিজে আপডেট হয়, তাই সাইট বদলালেও সাধারণত ঠিক থাকে।
6. বন্ধ করতে কালো উইন্ডোতে `Ctrl+C` বা উইন্ডো বন্ধ করুন।

## খ) Android ফোনে সরাসরি (Termux)
1. **F-Droid** থেকে Termux ইনস্টল করুন (https://f-droid.org/packages/com.termux/)। Play Store-এর Termux পুরনো, কাজ করবে না।
2. জিপ ফাইলটি ফোনের `Download` ফোল্ডারে রাখুন।
3. Termux খুলে একে একে চালান:

       termux-setup-storage
       pkg install -y unzip
       unzip ~/storage/downloads/media-downloader.zip -d ~
       cd ~/media-downloader
       bash termux-setup.sh

4. অ্যাপ চালু করতে (প্রতিবার):

       cd ~/media-downloader && bash termux-run.sh

5. ফোনের Chrome-এ খুলুন: **http://127.0.0.1:7860**। Termux ব্যাকগ্রাউন্ডে খোলা রাখতে হবে।
6. ডাউনলোড করা ফাইল Chrome-এর Downloads ফোল্ডারে যায়।

## গ) কম্পিউটারে চালিয়ে ফোন/ট্যাবলেট থেকে (iPhone সহ)
1. কম্পিউটারে (ক) অনুযায়ী চালান। "Use from your phone too?" প্রশ্নে **y** লিখুন, চাইলে একটি পাসওয়ার্ডও দিন।
2. কালো উইন্ডোতে `Phone (same Wi-Fi): http://192.168.x.x:7860` লেখা আসবে।
3. ফোনকে **একই Wi-Fi**-তে রেখে ওই ঠিকানা ফোনের ব্রাউজারে খুলুন। ফাইল ফোনেই ডাউনলোড হবে।
4. Windows Firewall অনুমতি চাইলে "Allow" দিন। শুধু বিশ্বস্ত নেটওয়ার্কে এভাবে চালান, পাবলিক Wi-Fi-তে নয়।

## ব্যবহার
লিংক পেস্ট → ধরন (ভিডিও/অডিও বা ছবি) → "তথ্য দেখুন" → কোয়ালিটি বেছে সম্মতি টিক দিয়ে "ডাউনলোড" → প্রগ্রেস শেষে ফাইল নামবে।
ছবির লিংকে একাধিক ছবি থাকলে (গ্যালারি/পোস্ট) সব একটি ZIP-এ আসে।

## Telegram থেকে নিজের চ্যাটের মিডিয়া
হোম পেজের নিচের "Telegram ডাউনলোডার" লিংকে (`/telegram`) যান। কাজ করে আপনার **নিজের অ্যাকাউন্টের লগইনে**।

**একবারের সেটআপ**
1. https://my.telegram.org-এ নিজের নম্বরে লগইন → **API development tools** → অ্যাপ তৈরি করুন (নাম যা খুশি) → **api_id** ও **api_hash** পাবেন।
2. অ্যাপের Telegram পেজে এ দুটি বসিয়ে সেভ করুন, তারপর ফোন নম্বর (+880...) দিন। Telegram অ্যাপে আসা কোড দিন (2-step পাসওয়ার্ড থাকলে সেটিও)।

**ব্যবহার**
- "চ্যাটের তালিকা লোড করুন" → চ্যাট বেছে নিন → ধরন (ছবি/ভিডিও/অডিও/ফাইল) ও সংখ্যা (সাম্প্রতিক থেকে) দিন → ডাউনলোড। একাধিক ফাইল ZIP হয়ে আসে।
- অথবা একটি নির্দিষ্ট মেসেজের লিংক (`https://t.me/channel/123`) পেস্ট করুন।

**সীমা ও নিরাপত্তা**
- যেসব চ্যাট বা মেসেজে "protected content" (সেভ/ফরওয়ার্ড বন্ধ) চালু আছে, সেগুলো **স্বয়ংক্রিয়ভাবে বাদ যায়** (তালিকায় 🔒 চিহ্নসহ)। এই সুরক্ষা ঘোরানোর কোনো ব্যবস্থা নেই।
- API কী ও লগইন সেশন শুধু আপনার ডিভাইসের `~/.media-downloader` ফোল্ডারে থাকে (শুধু আপনি পড়তে পারেন)। ফোল্ডারটি কাউকে দেবেন না।
- শুধু লোকাল মোডে চালু। ফোন/Wi-Fi মোডে (`0.0.0.0`) চালালে পাসওয়ার্ড (ACCESS_CODE) না দিলে Telegram অংশ বন্ধ থাকে, নইলে একই Wi-Fi-র অন্য কেউ আপনার অ্যাকাউন্ট ব্যবহার করতে পারত।
- সেশন মুছতে অ্যাপের "লগআউট" বোতাম চাপুন। Telegram-এর Settings → Devices থেকেও সেশন বন্ধ করা যায়।
- অল্প সময়ে অনেক ফাইল নামালে Telegram সাময়িকভাবে গতি কমাতে পারে (FloodWait), তখন অপেক্ষা করুন।

## লগইন লাগে এমন লিংক (কুকি)
"Sign in to confirm you're not a bot" বা প্রাইভেট কনটেন্টে ব্রাউজার থেকে সরাসরি কুকি নেওয়া যায় (কম্পিউটারে):
- `run-windows.bat` ফাইলটি Notepad-এ খুলে `set LOCAL_MODE=1` লাইনের নিচে যোগ করুন: `set COOKIES_BROWSER=firefox`
- Mac/Linux: `run-mac-linux.sh`-এ `export LOCAL_MODE=1 ...` লাইনের নিচে `export COOKIES_BROWSER=firefox`
- ওই ব্রাউজারে (Firefox সবচেয়ে নির্ভরযোগ্য; নতুন Chrome Windows-এ ব্যর্থ হতে পারে) আগে সংশ্লিষ্ট সাইটে লগইন থাকতে হবে।
- ভেরিয়েবলে `chrome`, `edge`, `brave` ইত্যাদিও দেওয়া যায়।
- ফোন (Termux)-এ এটি কাজ করে না। সেখানে `cookies.txt`-এর base64 `COOKIES_B64` ভেরিয়েবলে দিন।

## সমস্যা হলে
| লক্ষণ | সমাধান |
|---|---|
| `python` পাওয়া যায়নি | Python ইনস্টল করে "Add to PATH" টিক দিন, আবার চালান |
| তথ্য আনা যায় না / ৪০৩ | ফাইলটি আবার চালান (নিজে আপডেট হয়); না হলে ইন্টারনেট/VPN দেখুন |
| Sign in / bot চেক | উপরের কুকি অংশ |
| ফোন থেকে ঠিকানা খোলে না | একই Wi-Fi কি না, ফায়ারওয়ালে Allow, ও "y" দিয়েছেন কি না দেখুন |
| Termux-এ `pip` এরর | `pkg upgrade -y` চালিয়ে `bash termux-setup.sh` আবার দিন |
| ছবি পাওয়া যায় না | সব সাইটে কুকি লাগে; gallery-dl সব সাইট সাপোর্ট করে না |
| Telegram: কোড আসে না / সংযোগ হয় না | ফোন নম্বরে দেশের কোড (+880) আছে কি দেখুন; VPN/ইন্টারনেট পরীক্ষা করুন; api_id/hash আবার দিন |
